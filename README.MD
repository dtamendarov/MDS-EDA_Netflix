## Общая информация
Стек: pandas, numpy, matplotlib, seaborn  
Источники: NetflixShows.xlsx, OMDB API, открытые датасеты Kaggle

Инструкция для запуска проекта:
1. Скопируйте репозиторий 
2. Зарегистрируйтесь на сайте OMDB API и получите ключ 
3. Создайте файл секретов .env c ключом и файл .gitignore
4. создайте виртуальную среду и запустите requirements.txt
